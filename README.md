# ENIGMA 5789 + JIMMY AI: Codex of Nations Engine

An advanced geopolitical intelligence platform and multi-model forecast engine integrating ancient Maya temporal cycle dynamics, deep neural hazard modeling, and anime/manga sci-fi nation archetypes.

## Features
- **3D Rotating Earth Simulation:** Counter-clockwise (West-to-East) axial rotation built with Three.js.
- **Jimmy AI Cognition Suite:** Independent locked-series tracking ($P \leftrightarrow R$, $M \leftrightarrow R$, $P \leftrightarrow M$) and neural hazard calculations.
- **The Codex of Nations:** Detailed nation profiles combining trade profiles, geopolitical perception analyses, and anime/manga sci-fi archetypes.
- **Yaxche World Tree Network:** Scenario causality and probability branching graphs.
- **Cross-Platform Readiness:** Runs seamlessly on Phones, Tablets, Computers, and Console Web Engines.
